# SocialNest

SocialNest - это прототип социальной мини-платформы на Django.

Пользователи могут регистрироваться, авторизовываться, редактировать профиль и публиковать посты с текстом и изображениями. Для постов реализованы лента с пагинацией, просмотр, редактирование и удаление с проверкой прав доступа.

## Стек

* Python 3.10+
* Django 6.1
* SQLite
* HTML / Django Templates
* Bootstrap
* Pillow
* python-dotenv
* unittest / Django TestCase
* Ruff

## Возможности

### Пользователи

* регистрация;
* авторизация и выход;
* уникальный email;
* профиль пользователя;
* просмотр профиля другого пользователя;
* редактирование собственного профиля;
* загрузка аватара;
* описание профиля;
* дата рождения;
* валидация даты рождения;
* ограничение размера загружаемых изображений.

### Посты

* создание постов авторизованными пользователями;
* заголовок и текст поста;
* загрузка изображения;
* просмотр ленты;
* сортировка постов от новых к старым;
* пагинация по 10 постов;
* просмотр отдельного поста;
* редактирование собственных постов;
* удаление собственных постов;
* запрет редактирования и удаления чужих постов;
* минимальная длина текста поста.

## Установка

### Клонирование репозитория

```bash
git clone https://github.com/eternal-git-dev/django-social-proto
cd django-social-proto
```

### Создание виртуального окружения

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

## Аутентификация и права доступа

Для регистрации используется стандартный Django `UserCreationForm` с кастомной моделью пользователя.

Для авторизации и выхода используются стандартные `LoginView` и `LogoutView`.

Создание постов доступно только авторизованным пользователям.

Редактирование и удаление постов доступны только их авторам. Проверка владельца вынесена в общий `UserPassesTestMixin`.

Неавторизованный пользователь при попытке создать, изменить или удалить пост перенаправляется на страницу авторизации.

Попытка редактирования или удаления чужого поста приводит к ответу `403 Forbidden`.

## Работа с изображениями

Для пользователей и постов используются `ImageField`.

Изображения пользователей сохраняются в:

```text
media/avatars/
```

Изображения постов:

```text
media/posts/
```

В режиме разработки медиафайлы отдаются через `static()` в `urls.py`.

Размер загружаемых изображений ограничен валидатором — не более 5 MB.

Также реализована проверка даты рождения: дата не может находиться в будущем.

## Архитектура

Проект разделён на два Django-приложения:

### `users`

Отвечает за:

* модель пользователя;
* регистрацию;
* аутентификацию;
* профили;
* формы пользователей;
* пользовательские валидаторы.

### `posts`

Отвечает за:

* модель поста;
* создание и редактирование постов;
* удаление постов;
* ленту;
* пагинацию;
* формы постов.

Представления преимущественно реализованы с использованием Class-Based Views.

Общая логика представлений постов вынесена в mixin-классы для исключения дублирования.

## Основные URL

| URL                        | Назначение                          |
| -------------------------- | ----------------------------------- |
| `/`                        | Лента постов                        |
| `/users/register/`         | Регистрация                         |
| `/users/login/`            | Авторизация                         |
| `/users/logout/`           | Выход                               |
| `/users/<username>/`       | Профиль пользователя                |
| `/users/profile/edit/`     | Редактирование собственного профиля |
| `/posts/create/`           | Создание поста                      |
| `/posts/<post_id>/`        | Просмотр поста                      |
| `/posts/<post_id>/edit/`   | Редактирование поста                |
| `/posts/<post_id>/delete/` | Удаление поста                      |
| `/admin/`                  | Административная панель             |

## База данных

```text
db.sqlite3
```

Модель пользователя является кастомной и наследуется от `AbstractUser`.
